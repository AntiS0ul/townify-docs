# Command Reference

A grouped list of the commands you'll actually use on TownifyMC.

!!! tip "Looking for shortcuts?"
    [Useful Commands & Shortcuts](shortcuts.md) covers the short aliases, one-click menus, toggles, and in-game controls. In game, `/menu` opens the main menu, where you can reach most systems by clicking.

## Essentials & general

| Command | What it does |
|---------|-------------|
| `/menu` | Main server menu |
| `/spawn` | Teleport to server spawn |
| `/wiki` · `/docs` | Link to this guide |
| `/rules` | View the server rules |
| `/tpa <player>` | Request to teleport to a player |
| `/tpaccept` · `/tpdeny` | Respond to a teleport request |
| `/home` · `/sethome` | Teleport to / set a home |
| `/upgrades` | Buy more homes & player-warp slots |
| `/kit` | Kits menu |
| `/back` | Return to your last location |
| `/msg <player> <text>` | Private message |
| `/r <text>` | Reply to last message |
| `/afk` | Mark yourself away |
| `/discord` · `/dc` | Get the Discord invite |
| `/map` | Link to the live map |
| `/store` | Link to the online store |
| `/poses` · `/sit` · `/lay` · `/crawl` | Poses |

## Towny — town

| Command | What it does |
|---------|-------------|
| `/town` | Your town's info panel |
| `/town new <name>` | Found a town (needs Countryman #5) |
| `/town claim` | Claim the current chunk |
| `/town unclaim` | Unclaim the current chunk |
| `/town add <player>` | Invite a player |
| `/town set spawn` | Set town spawn |
| `/town spawn` | Teleport to town spawn |
| `/town deposit <amount>` | Fund the town bank |
| `/town set taxes <amount>` | Set resident taxes |
| `/town set perm` | Permission menu |
| `/town toggle pvp` | Toggle PvP in town |
| `/plot forsale <price>` | Put a plot up for sale |
| `/plot set perm` | Per-plot permissions |

## Sharing & access

| Command | What it does |
|---------|-------------|
| `/res friend add <player>` · `/res friend remove <player>` | Manage your Towny friends |
| `/plot set perm friend on` | Let friends build/use the plot you're in |
| `/plot trust add <player>` · `/plot trust remove <player>` | Trust a player on this plot |
| `/town rank add <player> <rank>` | Give a town rank (assistant, helper, sheriff, …) |
| `/cmodify <player>` · `/cmodify -<player>` | Add/remove access on a locked container |
| `/cinfo` · `/cpublic` · `/cprivate` · `/cremove` | Container lock info and settings |
| `/chopper on` · `/chopper off` | Allow/block hoppers on a locked container |
| `/tc` · `/nc` · `/ac` · `/g` | Town · nation · alliance · global chat |

See [Collaboration & Sharing](../towns/collaboration.md).
