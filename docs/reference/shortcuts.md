# Useful Commands & Shortcuts

The [Command Reference](commands.md) lists everything by system. This page covers the shortcuts: short aliases, one-click menus, toggles, and in-game controls that save you typing.

!!! tip "If you only remember one command"
    **`/menu`** opens the main server menu. Almost everything on this page can also be reached from it by clicking: kits, markets, jobs, warps, quests, rewards, upgrades, the Gem store, poses, and more.

## The top 10

The commands most players use every session:

| Command | What it does |
|---------|-------------|
| `/menu` | Main menu. Links to nearly every system |
| `/warp` | Travel menu: Overworld, Nether, End, PvP Arena, Dungeons, Spawn, your grave |
| `/rtp` · `/wild` | Random teleport into the wild |
| `/jobs` | Jobs menu |
| `/bal` | Your **Money and Gems** in one message |
| `/rankup` | Rank up if you can afford it |
| `/quests` | Today's daily quests |
| `/vote` | Vote menu with the voting links |
| `/market` | Browse player chest shops |
| `/town spawn` | Teleport to your town |

## Handy toggles

Turn things on and off to suit how you play:

| Command | Toggles |
|---------|---------|
| `/roadspeed` | [Road speed boosts](../world/travel.md#roads-travel-faster) on/off |
| `/nv` | Night vision (rank perk) |
| `/glow [color]` | Glowing outline, with `/glow list` for colors (Banshee rank) |
| `/tab scoreboard toggle` | Hide/show the sidebar scoreboard |
| `/tab bossbar toggle` | Hide/show the boss bar |
| `/dynmap hide` · `/dynmap show` | Hide/show yourself on the [live map](https://map.townifymc.xyz) |
| `/walkspeed <1-10>` · `/walkspeed 0` | Set or reset walk speed (rank perk) |
| `/flyspeed <1-10>` | Set fly speed (rank perk) |

The **Book Menu** item you get on join can be switched off (and back on) from `/menu`.

## In-game controls (no command needed)

Some features use clicks, jumps, and chat instead of commands:

| Do this… | …to |
|----------|-----|
| **Jump** on an Elevator Block | Go up to the next elevator in the column |
| **Sneak** on an Elevator Block | Go down to the next elevator |
| Type **`[item]`** or **`[i]`** in chat | Show off the item in your hand |
| **Shift-click** a chest/barrel while holding an item (twice) | Start creating a [chest shop](../money/shops.md#setting-up-your-own-chest-shop) |
| **Right-click** a Town Deed | Add bonus claim chunks to your town |
| **Right-click** a Boost Token | Start a server-wide 25% job boost |
| **Right-click** a Quest Reroll | Swap out that difficulty's daily quest |
| **Right-click** another player | Sit on them (if they allow it) |
| **Right-click** a Void Storage item | Take out a stack; **Shift + Left-click** to deposit everything that matches |
| Walk on **dirt paths / stone / brick** | Get a road speed boost |

## Teleport shortcuts

| Command | Where to |
|---------|----------|
| `/spawn` | Server spawn |
| `/home` · `/sethome` | Your homes (buy more with `/upgrades`) |
| `/back` | Your last location |
| `/town spawn` | Your town |
| `/nation spawn` | Your nation's capital |
| `/rtp <continent>` | A random spot on a chosen continent (see [Travel](../world/travel.md#random-teleport-rtp)) |
| `/rw` · `/nrw` | Resource World / Resource Nether |
| `/warp market` | The market district (rentable shop stalls) |
| `/warp crates` | Crate area |
| `/warp dungeons` | Dungeon hub |
| `/warp pvp` | PvP Arena |
| `/warp pinataparty` | Piñata Party arena |
| `/tpa <player>` | Ask to teleport to a player |
| `/tprequest <player>` | Same, using a **Teleport Request Token** (accept with `/tokenaccept`, deny with `/tokendeny`) |

!!! note "Tab completion is your friend"
    Most commands support **Tab** to auto-complete, including warp names (`/warp <Tab>`) and continents (`/rtp <Tab>`). If you're unsure of a name, type the start and press Tab.
