## Quick travel cheat sheet

| Want to… | Use |
|----------|-----|
| Open the travel menu | `/warp` |
| Land somewhere random | `/rtp` or `/wild` |
| Land on a specific continent | `/rtp europe`, `/rtp asia`, … |
| Gather resources | `/rw` (Resource World) · `/nrw` (Resource Nether) |
| Go home | `/home` · `/town spawn` |
| Fight | `/warp pvp` · `/warp dungeons` |

More shortcuts are on [Useful Commands & Shortcuts](../reference/shortcuts.md).
